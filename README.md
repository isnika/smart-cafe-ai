# Smart Café AI - Backend Microservices System

> Course project: Smart cafe management and sales system integrated with AI for intelligent recommendations, chatbot assistance, and automated operations.

---

## 🚀 Hướng Dẫn Chạy Nhanh (Quick Start)

Toàn bộ hệ thống Backend đã được đóng gói sẵn với Docker Compose. Bạn chỉ cần:

```bash
# 1. Tạo file cấu hình môi trường
cp .env.example .env

# 2. Khởi chạy toàn bộ hệ thống
docker compose up -d
```
